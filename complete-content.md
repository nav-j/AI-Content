# **Complete Artificial Intelligence (AI) Course**

## **KUBEARC ACADEMY — Beginner to Advanced + Practical AI**

This course is designed as a **complete 5-month AI course** for students, beginners, teachers, professionals, and aspiring AI creators. It starts with AI fundamentals and gradually moves to generative AI, prompt engineering, AI tools, automation, coding, machine learning, and real-world projects.

The course is designed for classroom teaching with **teacher notes, practical lab work, assignments, projects, and assessments**.

**Course structure**

- Duration: 5 months (20 weeks)
- Level: Beginner to Advanced
- Class frequency: 3 classes per week
- Total classes: 60
- Class duration: 60–90 minutes
- Learning mode: Theory + Practical + Projects
- Prerequisites: Basic computer knowledge

# **1. Course overview**

By the end of this course, students will be able to:

- Understand AI, Machine Learning, Deep Learning and Generative AI.
- Use AI tools for study, business, office, coding and content creation.
- Write effective prompts for different AI models.
- Create images, videos, presentations, websites and voice content using AI.
- Use AI for marketing, productivity and data analysis.
- Understand Python-based AI programming.
- Work with Machine Learning and introductory Deep Learning.
- Build AI-powered chatbots and applications.
- Automate tasks using AI tools.
- Build and present a final AI project.

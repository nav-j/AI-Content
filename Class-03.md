# **3. Introduction — Why do people confuse AI, ML and DL?**

Today, people commonly use the words AI, Machine Learning and Deep Learning as if they mean exactly the same thing.

But they are not the same.

For example:

- AI is the broad field.
- Machine Learning is one approach within AI.
- Deep Learning is a type of Machine Learning.
- Generative AI is a family of AI approaches that generate new content, often using deep learning.

### **Simple example**

Imagine you want a computer to identify whether a photograph contains a cat.

There are different approaches.

**Approach 1 — Traditional programming**

A developer manually writes rules:

- If the image has pointed ears.
- If it has whiskers.
- If it has a particular body shape.
- If it has a tail.

Then the program attempts to classify the image as a cat.

This is difficult because cats can look very different.

**Approach 2 — Machine Learning**

Instead of manually writing all rules, give the computer thousands of examples of cat and non-cat images.

The computer learns patterns from those examples and uses them to classify new images.

**Approach 3 — Deep Learning**

Use a neural network with multiple layers to learn complex visual patterns such as edges, shapes, textures and object features from images.

This can support highly accurate recognition when properly trained and evaluated.

## **Definition**

Artificial Intelligence is a field of computer science that focuses on developing systems capable of performing tasks that normally involve abilities associated with intelligence, such as learning, reasoning, perception, language understanding, problem-solving and decision-making.

### **AI can be used for:**

- Problem-solving
- Learning
- Decision support
- Pattern recognition
- Natural language processing
- Image analysis
- Prediction
- Content generation

### **Real-world AI examples**

| Application      | AI capability                          |
| ---------------- | -------------------------------------- |
| ChatGPT          | Language generation and assistance     |
| Face unlock      | Facial recognition                     |
| Google Maps      | Route and traffic-related intelligence |
| Netflix          | Recommendations                        |
| Spam filter      | Spam classification                    |
| AI medical tools | Medical image analysis and assistance  |
| Smart assistants | Speech and language interaction        |

### **Important point**

AI is not limited to robots.

A software application can use AI without having a physical body.

## **Definition**

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and use those patterns to make predictions, classifications or decisions without requiring every rule to be explicitly programmed.

In traditional programming, the developer writes rules.

In Machine Learning, we provide data and a learning algorithm. The algorithm learns a model from the data.

## **Example — Predicting house prices**

Suppose we have data:

| House size  | Bedrooms | Price    |
| ----------- | -------- | -------- |
| 800 sq ft   | 2        | ₹20 lakh |
| 1,000 sq ft | 2        | ₹25 lakh |
| 1,500 sq ft | 3        | ₹38 lakh |
| 2,000 sq ft | 3        | ₹50 lakh |
| 2,500 sq ft | 4        | ₹65 lakh |

The ML model learns relationships between the house features and prices.

Now we give the model a new house:

- Area: 1,800 sq ft
- Bedrooms: 3

The model may estimate a price of ₹46 lakh.

This is an example of a model prediction, not an exact property valuation.

## **Definition**

Deep Learning is a specialized area of Machine Learning that uses neural networks with multiple layers to learn complex patterns from data.

Deep Learning is inspired loosely by the structure of biological brains, but artificial neural networks are mathematical computing systems and are not equivalent to human brains.

## **What is a Neural Network?**

A neural network is a computational model made up of connected units often called neurons.

These units process information through layers.

### **1. Input Layer**

Receives information.

Example: an image, numerical data, text or sensor values.

### **2. Hidden Layers**

Process the information using mathematical operations and learned parameters.

Deep neural networks have multiple hidden layers.

### **3. Output Layer**

Produces the result.

Examples:

- Cat or dog classification
- Predicted price
- Recognized text
- Generated content

## **How does Deep Learning work?**

A simplified training process:

1. Input data is supplied to the network.
2. The network calculates an output.
3. The output is compared with the target answer during training.
4. A loss function measures the error.
5. The model adjusts its parameters to reduce the error.
6. This process repeats many times.

Over training, the network can learn useful patterns.

Modern Generative AI models are trained on large datasets and learn statistical patterns and representations.

When a user provides a prompt, the model processes it and generates an output based on its learned patterns.

For example, a language model generates text by repeatedly estimating what token or piece of text should come next based on the preceding context.

AI generates a new paragraph in response.

Image AI:

> Generate a realistic photograph of a small puppy sitting in a garden full of sunflowers during sunset.

AI generates an image based on the text and learned visual patterns.

### **Simple conceptual hierarchy**

- **AI** is the broad field.
- **ML** is one approach within AI.
- **DL** is one approach within ML.
- **GenAI** is a set of approaches for generating content, often using Deep Learning.

Important technical clarification for students: Generative AI is not simply a perfect nested circle inside Deep Learning. Much of modern GenAI is based on Deep Learning, but generative methods can also be built using other techniques. For classroom purposes, this diagram shows the common relationship, not a strict universal taxonomy.

| Feature      | AI                              | ML                              | DL                               | GenAI                                  |
| ------------ | ------------------------------- | ------------------------------- | -------------------------------- | -------------------------------------- |

# **9. Traditional Programming vs Machine Learning**

Students often ask:

> If we can write programs to do everything, why do we need Machine Learning?

The answer is that many problems have rules that are too complicated, numerous, changing or difficult to define manually.

## **Example — Spam detection**

### **Traditional programming approach**

The programmer creates rules:

- If the email contains "win money" → suspicious.
- If the email contains "free prize" → suspicious.
- If the email contains too many links → suspicious.

Problems:

- Spammers change their wording.
- Not every suspicious phrase is spam.
- Rules become difficult to maintain.
- New spam patterns may not match old rules.

### **Machine Learning approach**

Provide a model with many examples of spam and normal emails.

It learns patterns from the examples and uses those patterns to classify new emails.

# **14. Optional Python Demonstration — A Simple Machine Learning Model**

Teacher Demonstration · Beginner-friendly · 10 Minutes

Students have not yet reached the Python AI module, so this is an optional teacher-led demonstration rather than a graded coding exercise.

This example uses a Machine Learning model to predict whether a student passes or fails based on study hours.

```
from sklearn.tree import DecisionTreeClassifier# Training dataX = [[1], [2], [3], [4], [5], [6]]y = ["Fail", "Fail", "Fail", "Pass", "Pass", "Pass"]# Create modelmodel = DecisionTreeClassifier()# Train the modelmodel.fit(X, y)# Make a prediction for 3.5 study hoursprediction = model.predict([[3.5]])print(prediction)
```

### **Explain the code**

| Code                       | Meaning                              |
| -------------------------- | ------------------------------------ |
| `X`                        | Input data — study hours             |
| `y`                        | Correct labels — Pass or Fail        |
| `DecisionTreeClassifier()` | Machine Learning algorithm           |
| `model.fit(X, y)`          | Trains the model                     |
| `model.predict([[3.5]])`   | Predicts the outcome for a new input |

**Teacher explanation**

The computer is not given a rule such as `if study_hours >= 4: Pass`.

Instead, it receives examples of study hours and labels. It learns a pattern from the training examples and uses it to make a prediction.

Important: This is a tiny artificial dataset. It does not reflect real student performance and is only used to demonstrate the ML workflow.
